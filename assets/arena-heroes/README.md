# Arena character assets

Character models in this directory are from Kay Lousberg (KayKit), Adventurers Character Pack 1.0.

- Source: https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0
- Pack page: https://kaylousberg.itch.io/kaykit-adventurers
- License: CC0 1.0 Universal; see LICENSE-KayKit.txt.
- Models included: Barbarian, Knight, Mage, Rogue, and Rogue_Hooded.
- The sixth roster slot is a recolored Mage skin that reuses the Mage model file.

These are lightweight game prototypes; character clips are included in each GLB.
