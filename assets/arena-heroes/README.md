# Arena character assets

The lightweight ten-hero roster uses three openly licensed packs:

- KayKit Adventurers 1.0 by Kay Lousberg: `bintang.glb`, `perisai.glb`, `bara.glb`, `bayang.glb`, and `taufan.glb`. CC0 1.0; see `LICENSE-KayKit.txt`.
  - Source: https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0
  - Pack: https://kaylousberg.itch.io/kaykit-adventurers
- KayKit Skeletons 1.0 by Kay Lousberg: `skeleton-rogue.glb` and `skeleton-warrior.glb`. CC0 1.0; see `LICENSE-KayKit-Skeletons.txt`.
  - Source: https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Skeletons-1.0
  - Pack: https://kaylousberg.itch.io/kaykit-skeletons
- Gobkit Free Character Pack Vol. 3: `archer.glb`, `scout.glb`, `priestess.glb`, `footman.glb`, and `peasant-militia.glb`. CC0 1.0; the five models share the same low-poly fantasy style and named movement/combat clips.
  - Source: https://gobkit.itch.io/gobkit-free-character-pack-vol-3
  - License: CC0 1.0; see `LICENSE-Gobkit.txt`.

The GLB files include animation clips. The game scales the models and applies team tints at runtime. `Umbra`, `Zephyr`, `Nerisa`, `Ossix`, and `Valdor` now use the five matching Vol. 3 models above.
