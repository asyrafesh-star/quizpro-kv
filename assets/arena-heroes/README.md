# Arena character assets

The lightweight ten-hero roster uses three openly licensed packs:

- KayKit Adventurers 1.0 by Kay Lousberg: `bintang.glb`, `perisai.glb`, `bara.glb`, `bayang.glb`, and `taufan.glb`. CC0 1.0; see `LICENSE-KayKit.txt`.
  - Source: https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0
  - Pack: https://kaylousberg.itch.io/kaykit-adventurers
- KayKit Skeletons 1.0 by Kay Lousberg: `skeleton-mage.glb`, `skeleton-minion.glb`, `skeleton-rogue.glb`, and `skeleton-warrior.glb`. CC0 1.0; see `LICENSE-KayKit-Skeletons.txt`.
  - Source: https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Skeletons-1.0
  - Pack: https://kaylousberg.itch.io/kaykit-skeletons
- Gobkit Free Character Pack Vol. 3: `knight-captain.glb` (Knight Captain). CC0 1.0.
  - Source: https://gobkit.itch.io/gobkit-free-character-pack-vol-3

The GLB files include animation clips. The game scales the models and applies team tints at runtime.
