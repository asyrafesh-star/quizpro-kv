# Arena character assets

The Arena selection uses nine openly licensed KayKit models for a consistent low-poly look:

- KayKit Adventurers 1.0 by Kay Lousberg: `bintang.glb`, `perisai.glb`, `bara.glb`, `bayang.glb`, and `taufan.glb`. These are the five free Adventurers. CC0 1.0; see `LICENSE-KayKit.txt`.
  - Source: https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0
  - Pack: https://kaylousberg.itch.io/kaykit-adventurers
- KayKit Skeletons 1.0 by Kay Lousberg: `skeleton-rogue.glb`, `skeleton-warrior.glb`, `skeleton-mage.glb`, and `skeleton-minion.glb`. These are the four free Skeletons. CC0 1.0; see `LICENSE-KayKit-Skeletons.txt`.
  - Source: https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Skeletons-1.0
  - Pack: https://kaylousberg.itch.io/kaykit-skeletons
The GLB files include animation clips. The game scales the models and applies team tints at runtime. Gobkit files remain in the repository but are not used by the Arena selection.
