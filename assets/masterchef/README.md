# Quiz MasterChef assets

The chefs and action animations are procedural Three.js geometry created for
this demo. The kitchen uses KayKit Restaurant Bits, a low-poly mobile-friendly
asset pack. Its included license is CC0 1.0 Universal; attribution is optional.
The game layout is original and uses a color-coded prep loop, a central island,
and an interactive pantry. No Arena hero models are used in this game mode.

Official asset page: https://kaylousberg.com/game-assets/restaurant-bits
